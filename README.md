# Platón: materiales de estudio

Este repositorio reúne cinco recursos visuales para estudiar aspectos de la antropología, la educación y el pensamiento político de Platón. Los mapas conceptuales relacionan ideas de *La República* y *Las Leyes* entre sí y, en dos casos, las comparan con referentes contemporáneos.

## Recursos

1. [PLATÓN - DE LA ANTROPOLOGÍA A KALLIPOLIS (1).html](https://raymond-phil.github.io/PLATON/PLAT%C3%93N%20-%20DE%20LA%20ANTROPOLOG%C3%8DA%20A%20KALLIPOLIS%20%281%29.html) — Relaciona el mito de los metales, el carro alado y la división tripartita del alma con la organización de la ciudad ideal.

2. [PLATÓN - EVOLUCIÓN DEL MODELO DE ESTADO.html](https://raymond-phil.github.io/PLATON/PLAT%C3%93N%20-%20EVOLUCI%C3%93N%20DEL%20MODELO%20DE%20ESTADO.html) — Compara los modelos políticos expuestos en *La República* y *Las Leyes*.

3. [PLATON-FªPOLÍTICA-LAS LEYES-ESTRUCTURA INSTITUCIONAL.html](https://raymond-phil.github.io/PLATON/PLATON-F%C2%AAPOL%C3%8DTICA-LAS%20LEYES-ESTRUCTURA%20INSTITUCIONAL.html) — Presenta la estructura institucional de Magnesia en *Las Leyes*.

4. [FªSOCIAL-REPUBLICA PLATON VS DIVERGENTE.html](https://raymond-phil.github.io/PLATON/F%C2%AASOCIAL-REPUBLICA%20PLATON%20VS%20DIVERGENTE.html) — Compara la organización social de *La República* con la representada en *Divergente*.

5. [Niños-Platón-Kibutz.html](https://raymond-phil.github.io/PLATON/Ni%C3%B1os-Plat%C3%B3n-Kibutz.html) — Contrasta la educación infantil propuesta en *La República* con la experiencia de los kibutz.

## Cómo abrir y compartir las páginas

Seleccione cualquiera de los enlaces anteriores. Cada uno lleva directamente a su archivo HTML publicado mediante GitHub Pages, donde se muestra como página web. Para compartir un recurso en Google Classroom, copie la dirección de esa página concreta y publíquela como enlace.

Los enlaces requieren que GitHub Pages publique la rama `main` desde la carpeta `/(root)`. Si alguno no se abre, revise esa selección en **Settings → Pages** del repositorio y espere a que termine la publicación.

## `README.md` e `index.html`

`README.md` es la presentación del repositorio que GitHub muestra en su página principal. También puede servir como página de entrada de GitHub Pages. `index.html`, en cambio, es una portada escrita en HTML para el sitio web. No hace falta crear un `index.html` para acceder directamente a los cinco recursos mediante los enlaces anteriores; sería útil si se desea diseñar una portada web propia.
